사용 안내

설치와 로그인 없이 사용할 수 있습니다.

PDF에서 Excel까지

  1. PDF 선택으로 문서를 추가합니다.
  2. 문서와 읽을 페이지를 선택한 뒤 자동 추출을 누릅니다.
  3. 검토에서 원본과 값을 확인합니다. 누락된 항목은 PDF 위에 영역을 그려 다시 읽을 수 있습니다.
  4. 결과 확정 후 원하는 문서만 선택해 Excel 내보내기를 누릅니다.

자료는 어디에 보관되나요?

PDF와 추출값은 현재 브라우저 메모리에서 처리합니다. 서버로 전송하는 기능은 없습니다. 새로고침하거나 탭을 닫으면 사라집니다. 작업 저장은 수정값과 영역을 JSON 파일로 저장합니다. 다시 열 때 원본 PDF도 추가해 주세요.

PC용 프로그램과의 차이

이 버전은 PDF.js와 Tesseract.js를 사용하는 브라우저 시험판입니다. 기존 EasyOCR·학습 모델, 자동 확정, 글꼴 학습, 계정 간 동기화는 포함하지 않습니다. 인식률은 PDF와 PC 성능에 따라 달라지며, 측정 결과는 원본과 비교해 확정하세요.

빠르게 사용하려면

텍스트 PDF는 문자를 바로 읽고, 스캔 페이지에만 OCR을 실행합니다. 필요한 페이지만 지정하거나 한 항목의 영역만 읽으면 작업량을 줄일 수 있습니다. OCR 엔진과 언어 자료는 처음 사용할 때 내려받습니다.

인터넷 연결

화면은 GitHub Pages에 게시할 수 있습니다. 인식 엔진·한국어/영어 자료·Excel 모듈은 CDN에서 불러옵니다. 네트워크 정책으로 차단된 경우 엔진을 읽을 수 없다는 오류가 표시됩니다. GitHub와 CDN은 파일 다운로드 접속 기록을 남길 수 있습니다.
